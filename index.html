Les données sont enregistrées dans ta propre feuille Google Sheets. Colle ici la clé de connexion (l'URL de l'application web publiée depuis la feuille). Elle reste sur cet appareil : elle n'est pas écrite dans le code de la page.

Commence par https://script.google.com/macros/s/ et finit par /exec.

Comment obtenir cette clé ? (une seule fois, 3 minutes)
  1. Crée une feuille sur Google Sheets.
  2. Menu Extensions → Apps Script.
  3. Efface tout et colle le contenu du fichier apps-script/Code.gs du dépôt. Enregistre.
  4. Bouton Déployer → Nouveau déploiement, type Application web.
  5. « Exécuter en tant que » : Moi. « Qui a accès » : Tout le monde. Déployer et autoriser.
  6. Copie l'URL de l'application web (elle finit par /exec) et colle-la ci-dessus.

La même clé sert aux deux : collez-la sur chaque téléphone et vous partagez la même feuille.
